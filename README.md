# Barza — Valorile noastre

Landing page în limba română pentru prezentarea celor cinci valori și a aplicării lor.

## Fișiere

- `index.html`: structura și conținutul paginii
- `style.css`: stiluri și adaptarea pentru telefon
- `app.js`: valorile extensibile și etapele interactive
- `brand-original.png`: resursa de identitate furnizată pentru proiect

Pagina este statică și nu necesită instalare sau compilare. Deschideți `index.html` în browser sau serviți directorul printr-un server static.

Conținutul prezintă un concept de aplicare a valorilor. Practicile descrise necesită validare înainte de folosire ca angajamente publice. Elementele de identitate Barza nu sunt oferite sub o licență de reutilizare liberă.
